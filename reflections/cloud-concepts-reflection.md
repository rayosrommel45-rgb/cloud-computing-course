# Reflection: Cloud Computing in Daily Life and Version Control

## 1. Cloud Services I Use Regularly
In my daily life, I regularly use several cloud-based applications that make communication, productivity, and entertainment seamless. Three of the most common services I rely on are Google Drive for file storage and collaboration, Canva for graphic design, and GCash for digital financial transactions.

## 2. Identifying Service and Deployment Models
Each of these platforms utilizes specific cloud frameworks:
- **Google Drive** is classified as **Software as a Service (SaaS)** under a **Public Cloud** deployment model. It provides users with ready-to-use document editing and cloud storage tools hosted on public cloud infrastructure, eliminating the need to manage underlying servers.
- **Canva** is also a **SaaS** platform running on a **Public Cloud**. It delivers web-based graphic design tools directly to users through a browser without requiring local software installations.
- **GCash** operates as a **SaaS** application hosted within a secure **Public Cloud** infrastructure (integrated with financial data centers). It offers mobile wallet services accessible anytime via the internet while maintaining strict security compliance.

## 3. Git & GitHub for Cloud Projects
Version control systems like Git and GitHub are critical when working with cloud computing projects and infrastructure. Because cloud environments often involve collaborative configurations, scripts, and multi-user deployments, tracking changes meticulously is vital. GitHub helps teams collaborate smoothly by allowing multiple developers to work on separate branches simultaneously, merge updates seamlessly, and maintain a clear history of modifications. This prevents configuration errors, rolls back problematic updates easily, and ensures that everyone operates on the most accurate, up-to-date version of the cloud resource or code repository.
