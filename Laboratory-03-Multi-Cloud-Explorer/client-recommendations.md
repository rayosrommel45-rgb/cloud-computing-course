# Client Recommendations

## Client A – Startup Company

**Recommended Cloud Platform:** Amazon Web Services (AWS)

A startup company with a limited budget needs a cloud platform that is flexible and can easily grow as the business expands. AWS offers scalable services with a pay-as-you-go pricing model, making it suitable for startups. As the mobile application gains more users, AWS can automatically scale resources to meet demand.

**Recommended Services:**
- Amazon EC2
- Amazon S3
- Amazon RDS

---

## Client B – University

**Recommended Cloud Platform:** Microsoft Azure

The university already uses Windows Server, Microsoft 365, and Active Directory. Microsoft Azure integrates seamlessly with these Microsoft technologies, making migration easier and more efficient. It also provides secure identity management and cloud services for education.

**Recommended Services:**
- Azure Virtual Machines
- Azure SQL Database
- Microsoft Entra ID

---

## Client C – AI Research Company

**Recommended Cloud Platform:** Google Cloud Platform (GCP)

Google Cloud Platform is well known for its Artificial Intelligence and Machine Learning capabilities. It offers powerful computing resources and managed AI services that support research and large-scale data processing. GCP is also a leader in Kubernetes technology.

**Recommended Services:**
- Vertex AI
- Compute Engine
- Google Kubernetes Engine (GKE)

---

## Client D – Global E-Commerce Company

**Recommended Cloud Platform:** Amazon Web Services (AWS)

A global e-commerce company requires high availability, automatic scaling, and worldwide infrastructure. AWS provides multiple regions, availability zones, and reliable services that help ensure fast and secure access for customers around the world.

**Recommended Services:**
- Amazon EC2
- Elastic Load Balancing (ELB)
- Amazon CloudFront

---

# Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|----------------------|----------------------|---------------|
| Startup Company | AWS | Cost-effective, scalable, and flexible for growing businesses. |
| Enterprise Organization | AWS | Wide range of enterprise cloud services with global infrastructure. |
| Microsoft Environment | Microsoft Azure | Best integration with Microsoft products and services. |
| AI / Machine Learning | Google Cloud Platform | Advanced AI and Machine Learning tools such as Vertex AI. |
| Kubernetes Deployment | Google Cloud Platform | Google developed Kubernetes and offers Google Kubernetes Engine (GKE). |
| Global Web Application | AWS | Global infrastructure with multiple regions and automatic scaling. |
