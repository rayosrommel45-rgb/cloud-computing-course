# Reflection

## Reflection on Multi-Cloud Exploration

Completing this laboratory activity helped me understand the differences and similarities between the three major cloud service providers: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). I learned that while all three platforms provide essential cloud services such as virtual machines, storage, databases, and networking, each has its own strengths and advantages. AWS offers the widest range of services and global infrastructure, Microsoft Azure integrates well with Microsoft products, and Google Cloud Platform excels in Artificial Intelligence, Machine Learning, and Kubernetes.

Through this activity, I also learned how to compare cloud platforms based on their services, infrastructure, and business use cases. Creating recommendations for different client scenarios improved my understanding of selecting the most suitable cloud platform according to specific business requirements. In addition, using the Linux environment in KillerCoda allowed me to explore system information through command-line tools and appreciate how cloud virtual machines operate.

Overall, this laboratory strengthened my knowledge of cloud computing concepts, cloud service models, and Linux administration. These skills will be valuable in future cloud computing projects and real-world IT environments.
