# Amazon Web Services (AWS) Research

## Brief Overview
Amazon Web Services (AWS) is a secure cloud services platform offered by Amazon, providing compute power, database storage, content delivery, and other functionality to help businesses scale and grow.

## Global Infrastructure
AWS operates through a vast global infrastructure composed of Regions, Availability Zones (AZs), and Edge Locations strategically distributed worldwide to ensure high availability, low latency, and fault tolerance.

## Cloud Management Console
The AWS Management Console is a web-based interface that allows users to manage and monitor various AWS cloud resources, services, and billing from a centralized dashboard.

## Four (4) Core Services
1. **Amazon EC2 (Elastic Compute Cloud):** Provides secure, resizable compute capacity in the cloud for running virtual server instances.
2. **Amazon S3 (Simple Storage Service):** An object storage service offering industry-leading scalability, data availability, security, and performance.
3. **Amazon RDS (Relational Database Service):** Makes it easy to set up, operate, and scale a relational database in the cloud.
4. **AWS Lambda:** A serverless compute service that lets you run code without provisioning or managing servers.

## Three (3) Advantages
1. **Extensive Maturity and Ecosystem:** AWS has the longest history in the market, offering the largest selection of integrated services and partner solutions.
2. **High Scalability and Flexibility:** Allows organizations to scale resources dynamically up or down based on current business demands.
3. **Global Security and Compliance:** Built with high-grade security features and numerous global compliance certifications to protect sensitive workloads.

## Typical Enterprise Use Cases
- Hosting scalable web applications and mobile backends.
- Running big data analytics and data warehousing.
- Implementing enterprise disaster recovery and backup solutions.
